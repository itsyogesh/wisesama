# Local audit skill page research

The public `/skills` page extends the established documentation shell. It describes the actual versioned `wisesama-ci-audit` download, account-free local execution, report interpretation and limits. `/agents` and the public footer link to it. The package source and distribution contract are in [open-source skills](./OPEN-SOURCE-SKILLS.md).

Mobbin was searched specifically for developer documentation with command-line installation instructions. The actual returned images were opened inline:

- [PlanetScale installation](https://mobbin.com/screens/4b3a17e0-1a09-4f23-b671-f61d306c8341) keeps named command blocks immediately beside their purpose. Wisesama follows that ordering for extraction and standalone use, with existing copy recovery. Database connection and credential instructions are excluded.
- [Clerk setup](https://mobbin.com/screens/382be08d-b9cd-412e-b88f-aca632720e08) separates installation from subsequent configuration and attaches important conditions to the relevant step. Wisesama distinguishes downloading a checker, running it, and asking an agent to interpret the report. It requires no provider credential or account configuration.
- [Neon setup](https://mobbin.com/screens/94fb6fc0-0fb0-4358-b6da-534a1f5addb9) demonstrates copyable code and an explicit start action. Its modal and authenticated app context are not used for this public reading page.

These references inform structure only. Wisesama retains Satoshi, the existing dark/light documentation palette, article measure and navigation. No reference-product imagery, invented installation URL, fictitious hosted audit, security grade, illustration or customer claim is introduced.

The page leads with an inspectable download and license/runtime facts, then the exact CLI, evidence vocabulary and coverage. The checker remains offline; use through a coding agent follows that agent's data settings. The public MCP remains a separate read-only advisory interface.
